# Kılınç Fidancılık

Modern, sinematik ve responsive fidancılık e-ticaret vitrini. Fidan, ağaç, çiçek ve meyve ürünleri için tasarlanmıştır.

## Özellikler
- Responsive premium arayüz
- Ürün kategori filtreleri
- LocalStorage tabanlı sepet
- Bitki Bulucu etkileşimi
- Özgün inline SVG botanik illüstrasyonları
- Reduced-motion erişilebilirliği

> Ödeme, stok ve işletme iletişim entegrasyonları frontend sonrasında bağlanabilir.
